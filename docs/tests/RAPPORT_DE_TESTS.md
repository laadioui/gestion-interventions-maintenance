# Rapport de tests

Les tests automatisés couvrent :

- validations de saisie ;
- hachage et vérification de mot de passe ;
- création utilisateur ;
- refus des doublons ;
- création et affectation d'intervention ;
- refus d'affecter un technicien inactif ;
- clôture avec solution obligatoire ;
- création d'historique.

Le résultat final est consigné dans `FINAL_CHECKLIST.md` après exécution Maven.
